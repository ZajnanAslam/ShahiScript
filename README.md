# The ShahiScript Compiler

A fully featured, retro-inspired compiler with an elegant Urdu/Persian theme built for the **CS4031 Compiler Construction** course project. 

## Features
- **Full Compilation Pipeline**: Custom Lexer, Recursive Descent Parser, Semantic Analyzer, AST Optimizer, and Tree-Walk Interpreter.
- **Visualizer Web App**: A beautiful web application built with Flask and D3.js to visualize the Lexer tokens and the Abstract Syntax Tree (AST) generated by the parser.
- **Language Features**: Support for variables, complex scoping, while/do/for loops, if/else conditionals, functions with return statements, and dynamic types (adad, ashariya, jumla, haqeeqat).

## Quick Start (CLI)
To run a ShahiScript file directly from the terminal, use `compiler.py`.

```bash
# Execute a script
python compiler.py examples/01_hello.shahi

# Execute a script and see the entire compilation process (Tokens, AST, Optimization)
python compiler.py examples/02_math_optimizer.shahi --debug

# Start the interactive REPL
python compiler.py --interactive
```

## Parsing Visualizer (Web App)
To launch the beautiful graphical visualizer:
```bash
python app.py
```
Then visit `http://127.0.0.1:5000` in your web browser.

## Compiler Architecture (CS4031 Deliverables)
1. **Lexical Analysis** (`lexer.py`): Converts code into tokens using Regex matching.
2. **Syntax Analysis** (`parser.py`): Recursive descent parser that generates an Abstract Syntax Tree (AST).
3. **Semantic Analysis** (`semantic.py`): Traverses the AST to build scoped Symbol Tables and checks for undeclared variables.
4. **Intermediate Optimization** (`optimizer.py`): Constant folding (e.g. `2 * 3` becomes `6` before execution) and Dead Code Elimination.
5. **Code Execution** (`interpreter.py`): Tree-walk interpreter to execute the optimized AST.
